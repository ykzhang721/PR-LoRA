# Recorded paper results

These JSON files are historical measurements copied from the research runs,
not results generated by the CPU smoke tests. All numeric conditions in each
selected source artifact are retained, including settings outside the final
main table. Source locations and SHA-256 hashes appear in
[PROVENANCE.json](../experiments/paper/PROVENANCE.json).

| File | Contents |
|---|---|
| `main_qwen3_8b.json` | Seven behaviors, base/steering, three adapter methods × ten seeds |
| `main_original_five_seeds.json` | Earlier five-seed supplement used by historical plots |
| `full_mmlu_qwen3_8b.json` | Base accuracy and ten seeds each for standard/PR on full MMLU |
| `truthfulqa_and_sampled_mmlu.json` | Secondary five-seed evaluation, plus original behavioral extensions |
| `dpo_baseline.json`, `dpo_budget.json` | Low-update baseline and data/update budget experiments |
| `loreft_baseline.json`, `pissa_baseline.json` | Extended baselines |
| `ablation_components.json` | Direction/random initialization and anchor ablations |
| `svd.json` | Aggregate effective ranks and direction cosines |
| `rank_ablation.json`, `mmlu_tradeoff.json` | Rank and step/anchor experiments |
| `multi_vo_rank6.json` | Joint behavior control with V/O adapters at rank 6 |
| `generation_scores.json` | Per-prompt judge scores, counts and rates; response text omitted |

```bash
python scripts/summarize_results.py
```

This prints the complete main table with standard deviations, adjusted
per-behavior p-values and the paired macro-level test. It fails on missing
seeds rather than silently substituting zero or averaging partial results.

For plotting with historical `mechanistic_analysis.py`, the driver expects
the five-seed artifact at `benchmarks/results/supplement/results.json` and
the tradeoff artifact at `benchmarks/results/mmlu_tradeoff/results.json`.
Copy the corresponding recorded files there to plot historical measurements,
or populate the paths with newly run experiments. Keep recorded and newly
computed measurements in separate workspaces.
